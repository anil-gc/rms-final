# Restaurant Management System

Restaurant workspace for a small restaurant operating from one location in Nepal. The
existing prototype is maintained separately and has not been copied or modified.

Phase 1, Phase 2, and the React authentication frontend are complete. Phase 3
adds restaurant profile, menu catalogue, and table management on a separate
local review branch. Ordering, kitchen, billing, and inventory remain future work.
