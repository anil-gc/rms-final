# Restaurant Management System

Backend for a small restaurant operating from one location in Nepal. The
existing prototype is maintained separately and has not been copied or modified.

Phase 1 is verified. Current work is Phase 2: accounts and authentication.
No frontend or restaurant business workflows are implemented.
