# Restaurant Management System

Restaurant workspace for a small restaurant operating from one location in Nepal. The
existing prototype is maintained separately and has not been copied or modified.

Phases 1-3 provide authentication/staff, restaurant profile, menu catalogue
and tables. Phase 4 adds Waiter orders and Cashier batch approval locally on
`feature/order-management`. Kitchen, billing and inventory remain future work.
